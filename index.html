Import Pick List

Two or more different items are sharing the same code, so a scan of one could get logged as progress on the wrong row. Give each item its own unique code in your sheet and re-import.

Expected columns: Item Code, Item Name, Qty Required — in that order, headers in row 1. Download the ready-made template below if you don't have one yet.

or paste manually

Paste directly from Excel (tab-separated) or type comma-separated. Unchecked = replaces the current list. Checked = new codes are added and repeated codes just top up the required qty, without touching progress already picked. Each item should have its own unique code.
